# Telegram Mini App LAVIE

Mini App открывает тот же сайт салона внутри Telegram: услуги, мастеров, регистрацию, выбор времени, клиентские чаты и кабинет мастера. Аккаунты и записи хранятся в `beauty.sqlite3`. Telegram-профиль сам по себе не даёт прав менеджера или мастера: нужен отдельный вход по логину и паролю.

Токен бота храните только в локальном `.env` (он не входит в Git и архив):

```dotenv
TELEGRAM_BOT_TOKEN=токен_из_BotFather
TELEGRAM_MINI_APP_URL=https://ваш-домен/
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,ваш-домен
DJANGO_CSRF_TRUSTED_ORIGINS=https://ваш-домен
```

Для постоянного HTTPS-хостинга запустите Django и `python manage.py run_telegram_bot --configure` в двух отдельных процессах. Команда настроит кнопку и начнёт polling. Не запускайте одновременно два polling-процесса одного бота. `/start` и `/salon` показывают кнопку «Открыть LAVIE». Без публичного HTTPS-адреса бот отвечает без кнопки: `127.0.0.1` на телефоне указывает на сам телефон.

Для временного показа без постоянного хостинга установите [cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/), затем из папки проекта выполните `python start_telegram_local.py`. Скрипт запускает локальный сайт, временный Cloudflare Quick Tunnel и бота. Компьютер и этот процесс должны оставаться включёнными; адрес меняется при каждом запуске. `Control+C` останавливает демонстрацию.

В режиме временного туннеля административные маршруты закрыты. Перед любым публичным запуском смените временные пароли, задайте новый `DJANGO_SECRET_KEY`, выключите отладку и используйте полноценный сервер приложения со статикой и HTTPS. Текущая локальная конфигурация предназначена для прототипа.
