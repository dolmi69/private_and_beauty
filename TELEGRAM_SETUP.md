# Telegram-бот и Mini App клиники

Mini App — существующий русский сайт внутри Telegram, с теми же страницами,
дизайном, чатом и SQLite-базой. Отдельный дубликат заявок не создаётся.
Админка остаётся защищена логином и паролем сотрудника; Telegram-профиль
не предоставляет административных прав.

## Локальное подключение

Токен хранится только в `.env` (он исключён из Git и архивов):

```dotenv
TELEGRAM_BOT_TOKEN=токен_из_BotFather
TELEGRAM_MINI_APP_URL=https://ваш-домен/
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,ваш-домен
DJANGO_CSRF_TRUSTED_ORIGINS=https://ваш-домен
```

Запустите Django и бота в двух отдельных терминалах. В текущей Windows-папке:

```powershell
..\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8001
..\.venv\Scripts\python.exe manage.py run_telegram_bot --check
..\.venv\Scripts\python.exe manage.py run_telegram_bot --configure
```

На Mac после установки зависимостей используйте `python manage.py`.
Последняя команда настраивает команды бота и кнопку меню, затем запускает polling.
Не запускайте одновременно два polling-процесса одного бота.

Без HTTPS-адреса бот отвечает на `/start`, но не показывает неработающую кнопку.
С адресом `/start` и `/clinic` показывают «Открыть клинику», а меню — «Клиника».
После изменения `.env` перезапустите Django и бота.

## Что ещё нужно для открытия с телефона

Публичный HTTPS-адрес Django-приложения: постоянный хостинг или временный туннель
для демонстрации. `127.0.0.1` на телефоне относится к самому телефону.
Перед публичным запуском смените временный пароль `admin`:

```bash
python manage.py changepassword admin
```

Для постоянного хостинга также настройте секретный ключ, `DJANGO_DEBUG=false`,
HTTPS, обслуживание статики и сервер приложения вместо `runserver`.
Нельзя публиковать текущую отладочную конфигурацию и пароль `admin/admin`.

В BotFather можно дополнительно включить Main Mini App в профиле бота,
указав тот же HTTPS-адрес. Кнопки в сообщении и меню работают без этого шага.

Не отправляйте медицинские жалобы самому боту: вводите их в чат приложения.
Бот реагирует только на команды и не пересылает жалобы в ГигаЧат.
Чат приложения сохраняет прежние правила: без диагноза, запись через форму,
подтверждение администратором, локальный деморежим без ключа ГигаЧата.

Документация: [Mini Apps](https://core.telegram.org/bots/webapps),
[Bot API](https://core.telegram.org/bots/api).
# Запуск без хостинга

Временный режим использует Cloudflare Quick Tunnel. Компьютер должен быть включён и подключён к интернету. Адрес меняется при каждом запуске; скрипт автоматически обновляет кнопку бота.

1. Установите `cloudflared` по официальной инструкции: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/
2. Укажите токен бота в локальном `.env` (не отправляйте этот файл другим).
3. Остановите ранее запущенный бот и временный сервер на порту 8002.
4. В активированном виртуальном окружении из папки проекта выполните `python start_telegram_local.py`.
5. Откройте https://t.me/hospitalpobot и нажмите «Клиника» или отправьте `/start`.

Публичный процесс использует `config/telegram_preview.py`: DEBUG выключен, все маршруты кроме страниц посетителя и API записи/чата закрыты. Админка с временным паролем доступна только через обычный локальный сервер. База записей общая. Окно запуска нужно оставить открытым; Ctrl+C останавливает демо.
