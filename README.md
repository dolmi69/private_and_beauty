# LAVIE — демонстрационный салон красоты

Русский сайт на Django 6.1.1 и SQLite: розовая адаптивная витрина, каталог услуг и мастеров, запись на свободное время, личные кабинеты, приватные чаты и календарь загрузки. Имена, контакты, цены и адрес в демоверсии вымышлены.

## Быстрый запуск

Нужен Python 3.12+. В папке с `manage.py`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py seed_slots
python manage.py createsuperuser
python manage.py runserver 127.0.0.1:8001
```

Для Windows PowerShell: `py -3.13 -m venv .venv`, затем `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` и `.\.venv\Scripts\python.exe manage.py ...`. В уже настроенной общей папке доступен `..\.venv\Scripts\python.exe`. Откройте <http://127.0.0.1:8001/>. `start_mac.command` автоматизирует первые шаги на macOS.

Новая база называется `beauty.sqlite3`. Прежняя медицинская `db.sqlite3` оставлена без изменений и сайтом LAVIE не используется. Миграции автоматически создают шесть вымышленных мастеров и девять услуг; `seed_slots` добавляет часы 10:00–20:00 с понедельника по субботу на ближайшие 30 дней. Команду можно повторять: существующие часы не дублируются. Для продолжительной работы запускайте её регулярно. В прототипе любая услуга занимает 60 минут.

## Как работают роли

- **Клиент** регистрируется на `/register/`, выбирает услугу, дату, доступного мастера и время на `/booking/`. В `/cabinet/` он видит свои записи, может отменить ожидающую запись и общаться с мастером по конкретной записи.
- **Мастер** получает аккаунт от менеджера. После входа ему доступны только `/specialist/` с календарём и `/specialist/chats/` с приватными чатами своих клиентов. День календаря показывает загрузку, клиентов, услуги, статусы и свободные окна. Встроенный помощник отвечает на вопросы вроде «Во сколько я освобождаюсь во вторник?» по расписанию именно этого мастера.
- **Менеджер** создаётся через `python manage.py create_manager ИМЯ` или как суперпользователь. На `/manager/dashboard/` открывается защищённая админ-панель записей; на `/manager/team/` создаются аккаунты мастеров с временными паролями. Менеджер подтверждает заявки, редактирует услуги и часы в `/admin/`.

Публичная регистрация всегда создаёт клиента; выбрать права мастера или менеджера через неё нельзя. Чаты доступны только клиенту и мастеру соответствующей записи. Для работы локального помощника ключ не требуется. Если в `.env` задать `GIGACHAT_CREDENTIALS` и оставить `CHAT_FORCE_MOCK=false`, ответы помощника мастера могут формироваться GigaChat; внешнему сервису передаются только суммарные данные расписания, без имён, телефонов и текстов чатов. При недоступности API работает локальный ответ.

## Структура

```text
everwell-ru/
├── config/settings.py                 # Настройки Django, SQLite, язык и часовой пояс
├── config/urls.py
├── clinic/models.py                  # Мастера, услуги, время, записи, аккаунты и чаты
├── clinic/views.py                   # Публичные страницы и API записи
├── clinic/portal.py                  # Календарь, чаты и помощник мастера
├── clinic/services.py                # Локальный помощник и GigaChat
├── clinic/scheduling.py              # Свободные часы и расчёт загрузки
├── clinic/access_middleware.py       # Разделение рабочих зон
├── clinic/admin.py                   # Панель менеджера
├── clinic/templates/clinic/          # Шаблоны страниц
├── clinic/static/clinic/             # Стили, JS и иллюстрация
├── clinic/migrations/                # Схема и начальные данные
├── manage.py
├── start_mac.command
└── requirements.txt
```

Проверки: `python manage.py check`, `python manage.py makemigrations --check --dry-run`, `python manage.py test clinic`.

## Перенос и Telegram

`python build_mac_archive.py` собирает новый архив `lavie-beauty-mac.zip` с согласованной копией `beauty.sqlite3`, но без `.env` и токена бота. На Mac следуйте [MACOS_SETUP.md](MACOS_SETUP.md). Telegram Mini App использует тот же сайт; условия временного HTTPS-туннеля приведены в [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md). Локальный сервер Django подходит для демонстрации, для постоянной публикации нужен отдельный хостинг и защищённые настройки.
