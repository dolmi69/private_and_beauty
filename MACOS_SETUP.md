# LAVIE на MacBook

1. Распакуйте `lavie-beauty-mac.zip`, откройте Terminal в папке `lavie-beauty`.
2. Установите Python 3.12 или новее с [python.org](https://www.python.org/downloads/macos/), если его нет.
3. Выполните `chmod +x start_mac.command`, затем `./start_mac.command`.
4. Откройте <http://127.0.0.1:8001/>. Для остановки сервера нажмите `Control+C`.

Скрипт создаёт виртуальное окружение, устанавливает зависимости, применяет миграции и добавляет часы на ближайшие 30 дней. Архив содержит вымышленную демонстрационную базу `beauty.sqlite3`; файл `.env` с ключами в него не входит. В архивной демоверсии локальный менеджер входит через `/manager/dashboard/` с ранее согласованными временными данными `admin` / `admin`. Для любого публичного доступа **сначала смените пароль**: `python manage.py changepassword admin`.

Мастер демоверсии входит через `/login/`; его данные указаны в сопроводительном сообщении к архиву. Если архив пересобран без базы, создайте менеджера командой `python manage.py createsuperuser`, а аккаунты мастеров — в `/manager/team/`.

Клиенты могут зарегистрироваться на сайте и выбрать услугу, день, мастера и время. Помощник мастера без GigaChat отвечает по локальному календарю. Для подключения GigaChat заполните `GIGACHAT_CREDENTIALS` в `.env` и перезапустите сайт.
